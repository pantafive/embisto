# Security

embisto fetches URLs other people choose, so it guards the network it runs in and its own memory against the pages it fetches: [docs/hardening.md](docs/hardening.md) describes how. Who may call it, and how often, is for whatever serves it to decide.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's security advisories](https://github.com/pantafive/embisto/security/advisories/new), not in a public issue. Include what you sent, what you saw, and the version or commit you ran.

If that form does not open for you, open an issue that asks for a private channel and says nothing about the vulnerability. The maintainer then opens a draft security advisory and invites you to it, and the report goes there.

You will get an answer within a few days. Once a fix is released, the advisory is published with credit to you, unless you prefer otherwise.

## Supported versions

Fixes go into the latest release.
