# Security

embisto fetches URLs other people choose, so it is built to be pointed at the internet: [docs/hardening.md](docs/hardening.md) describes what it guards against.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's security advisories](https://github.com/pantafive/embisto/security/advisories/new), not in a public issue. Include what you sent, what you saw, and the version or commit you ran.

You will get an answer within a few days. Once a fix is released, the advisory is published with credit to you, unless you prefer otherwise.

## Supported versions

Fixes go into the latest release.
